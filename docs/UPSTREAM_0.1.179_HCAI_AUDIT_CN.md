## 生产风险

### 长上下文计费行为变化

上游将长上下文计费门控改为“分组开关或账号开关任一启用即生效”。存量部署中分组开关通常为启用、账号开关通常为关闭，因此超过 272k 上下文的 OpenAI 请求可能从本版本开始按长上下文倍率计费。

发布前必须确认业务是否接受该账单变化；若不接受，应在升级前将相关分组的 `long_context_pricing_enabled` 关闭，并记录变更结果。

### 数据库迁移

迁移 226 使用 `CONCURRENTLY` 创建索引，预计不会阻塞正常读写，但大表构建可能持续较久。升级前确认磁盘空间、锁等待和迁移日志；不得在多个节点同时执行迁移。

### 多节点后台任务

保留 HCAI 共享 Leader 锁参数。日本区域共享 Redis/数据库的节点应只允许一个节点执行受全局锁保护的任务；台湾、美国独立 Redis 节点仍依赖数据库锁协调。发布期间需观察锁获取、任务跳过和任务执行日志。

## 建议发布顺序

1. 备份数据库并确认迁移状态。
2. 确认长上下文计费口径，必要时关闭相关分组开关。
3. 升级日本主节点，执行迁移并检查健康状态、数据库连接和后台锁。
4. 依次滚动升级日本02、日本03，每次确认请求、Redis、后台任务和运维节点标识正常。
5. 升级台湾，确认独立 Redis、共享数据库、异步图片对象存储和 CORS 链路。
6. 最后升级美国，确认 P2P 数据库连接、独立 Redis 和启动耗时。
7. 观察至少一个完整后台任务周期后再结束发布窗口。

## 回滚边界
