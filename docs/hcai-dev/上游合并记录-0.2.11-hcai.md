历史提交 `a1501cd4453f5e06a70ab743e64389d5249d24c3` 定义了 CC Switch 订阅/总配额/速率窗口/余额四模式；旧 0.2.8 HCAI 基线已只剩简化 extractor，与功能清单不一致。本次按保护全部 HCAI 定制要求恢复到上游新抽出的 `CC_SWITCH_USAGE_SCRIPT`，保持单一调用入口。保留原用量字段、无限订阅、中文窗口说明及请求头，同时修正零月用量不能错误回退周用量，保留 inactive/error 识别和上游 URL 去重。新增测试对实际 deeplink 解码后的脚本执行四模式与失败响应；不是仅测试字符串包含。

### 多区域与运行时风险

余额预占使用本区域 Redis，跨区域不共享；首请求放行、费用估算及 Redis fail-open 使其不是绝对余额硬限额。Key 创建频率也按 Redis 数据集累计，活动数量查询共享 DB 但 count/create 非原子。保持这些上游语义，不擅自改变 HCAI Redis 拓扑或生产参数。部署规范已同步说明。

渠道图片价留空继承官方目录是上游计费修复，并非 HCAI 展示优先规则变化；若原先依赖留空图片输出免费，应在部署前明确核对显式 0 配置。无新增 SQL 不代表配置/业务行为可无条件回退；当前未执行线上流量或恢复验收。
