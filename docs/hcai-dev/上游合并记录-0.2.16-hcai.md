## 迁移、配置及回退

新增文件按完整名字执行，两个 242 文件不同名，不覆盖旧迁移：

| 迁移 | 作用 |
| --- | --- |
| 242_group_i18n.sql | groups.i18n JSONB 非空默认空对象 |
| 243_gemini_cached_contents.sql | 缓存绑定表及 public_id 唯一、账号/Key 索引 |
| 244_gemini_cached_contents_channel_usage.sql | 保存创建时渠道计费口径 |
| 245_gemini_cached_contents_mutation_lease.sql | 修改意图 token/lease 与待恢复索引 |

新增 gateway.gemini_cached_content_max_ttl_seconds，默认 86400 秒；第三方显式缓存需上游明确支持且保持绑定账号，不能对任意号池网关启用。Vertex API Key 不支持显式缓存/批量生图，服务账号能力另行区分。

迁移为新增表/列/索引，仍有 DDL 锁和生产数据规模风险。旧程序不提供缓存接口与后台恢复，回退前必须处理进行中的缓存修改及上游存储费用，不能承诺只换旧二进制即可完整回退。保留原表与迁移记录，不自动删列。生产备份恢复、副本迁移、真实上游缓存及多区域演练未执行。
