- OpenCode 定时探测 provider 注入 HCAI GlobalBackgroundTasks；纯流量节点不能获取任务锁。

- 账户更新及 integration fixture 补齐 HCAI SQL 行锁、3 返回值、返利来源参数和 RedeemService 设置依赖。
- RiskControlView 测试自动合并重复声明被消除；上游关键词测试改为断言 HCAI 同步落库，未改变业务为异步。
- Wire 重生成补入 google/subcommands v1.2.0 的 go.sum 校验，go.mod 未修改。

新增 `238b_content_moderation_engine_meta.sql`、`239_channel_reasoning_effort_multipliers.sql`、`240_affiliate_ledger_operation_id.sql`。均为追加列/索引或显式兼容回填；不得删除已发布迁移。推理强度倍率和渠道定价属于计费展示/计算链路，升级后须核对渠道配置与回退行为；线下提现唯一索引要求保留 operation_id。
