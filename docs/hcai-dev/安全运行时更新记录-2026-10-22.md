# 安全运行时更新记录

日期：2026-10-22（Asia/Shanghai）。基线：`v0.2.17-hcai`，安全更新分支：`codex/security-runtime-20261022`。本记录对应 Go 标准库证书信任修复和 Node.js 构建环境安全补丁；未部署生产。

## 变更

- `backend/go.mod` 从 Go 1.27.2 更新至 Go 1.27.3，修复 GO-2026-6809 / CVE-2026-111943。Go 服务必须使用新工具链重新编译，不能只更新服务器上的 Go。
- `Dockerfile`、`deploy/Dockerfile`、`backend/Dockerfile` 的 Go 构建镜像更新至 `golang:1.27.3-alpine`。
- CI 和 Linux amd64 Release 工作流的 Node.js 从浮动 `22` 固定为 `22.23.4`。
- Docker 前端构建镜像从浮动 `node:24-alpine` 固定为 `node:24.22.1-alpine`，覆盖 Node.js 24 分支安全修复；本项目生产的 systemd 二进制不直接运行 Node.js。

## 影响边界

本次从已发布 `v0.2.17-hcai` 建立独立安全更新分支，不包含尚未发布的用量日志修复。未修改价格、模型路由、HCAI 首页、插件、国际化或数据库迁移。macOS ChatGPT 应用自带的 `cua_node` 属于外部应用运行时，不由本仓库版本控制，需另行核验。
