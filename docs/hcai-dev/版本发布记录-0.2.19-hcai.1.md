## 内容与升级影响

- Token 请求统计改为一次聚合，使用 PostgreSQL 缓存表与事务 advisory lock，跨应用无须共享 Redis；逻辑有效期 120 秒、每分钟截止时间、原统计指标与时长不变。
- 运维默认刷新间隔 60 秒，保留数据库已有设置；前端防重、筛选取消/竞态隔离、隐藏暂停、卸载清理、手动刷新及截至时间显示。
- 新增 `249_ops_token_stats_cache.sql`，程序正常迁移流程建小缓存表和索引，不回填/重建 usage_logs。冷计算最长 55 秒，总处理/等待最多 58 秒，HTTP 65 秒。
- 需要所有共享数据库应用升级才能完整限制跨实例重查询；混跑旧版仍可能直接扫描。缓存异常不绕过保护直查，冷请求可能超时。正常统计新鲜度约落后 1～2 分钟。
- 本次生产只读核验按用户要求跳过；没有生产计划/IO 改善结论，没有生产备份/恢复、真实上游付费调用或部署验收。
