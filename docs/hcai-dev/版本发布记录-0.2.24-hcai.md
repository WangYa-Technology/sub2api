## 待发布说明草案

保留 HCAI 首页/加载、插件持久化、模型广场渠道展示优先与独立官方价/人民币展示、菜单凭据隔离、CC Switch、沙箱支付/返利、异步图片/MinIO、WeCom 与多节点协调。新增上游 Exa、ToolSearch/搜索来源、模型 ID 复制、长上下文目录及网关安全/协议/重试/刷新保护；Grok 搜索成功计数、compaction 5m 与耗时加权 TPS 属于行为变化。HCAI 为新统计口径隔离 v2 共享缓存，保留全局计算锁；补齐 DB-only OAuth 刷新租约的落库时间预留。两项新增回归均待提交步骤执行。

本轮无新增迁移或依赖锁/工具链变更，12 个 HCAI SQL 保留；Exa 不允许在未完成升级的混版本集群启用，回退前先恢复旧版支持的供应商配置；回退不能恢复轮换前 OAuth 凭据。旧版二进制、配置、备份及集群观测待部署单核对。已知 TLS Transport 指纹复用边界没有在本版修复。
