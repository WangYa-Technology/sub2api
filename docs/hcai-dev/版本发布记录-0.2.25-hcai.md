## 迁移、兼容与风险摘要

无新增/重写迁移：317 个 HCAI SQL、上游 305 个 SQL 全部原样保留，按完整文件名核对。无必填环境变量、Wire 或前端锁文件变更；go.mod/go.sum 更新 gorilla/websocket，保留 MinIO。Go1.27.4、Node22.23.4、pnpm11.10.0 基线保持。

分组同步和身份模板均需显式启用。所有节点升级前禁用新模板与自动文字同步，避免旧节点发字面模板或丢失新托管键。回退先移除模板、关闭同步并排空连接；已被同步覆盖的本地文字需要原配置恢复，换旧二进制不会自动恢复。无需因本轮移除数据库表；迁移重放、真实拓扑/备份和多节点验收仍待隔离环境核实。详情以部署前审查为准。
