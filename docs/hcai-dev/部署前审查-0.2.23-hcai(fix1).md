# 部署前审查：0.2.23-hcai(fix1)

日期：2026-11-19。状态：源码候选审查；尚未生产部署。

## 更新内容与功能影响

[上游 0.2.23 Release](https://github.com/Wei-Shaw/sub2api/releases/tag/v0.2.23)增加 GPT-6.2 Sol/Astra、套餐控制的 Ultra Fast、渠道 Ultra Fast 倍率；GPT-6.2 Ultra Fast 在太平洋时间 2027-03-01 00:00 前按 3 倍、之后 6 倍。修复 Anthropic/OpenAI 协议桥的缓存写入 TTL、总量缺口和 1h 计费，改进 OpenAI 流式首次输出前超时换号、持续流空闲计时与透传 flush。新增迁移 252。

这些是功能和计费影响：新模型可用范围、渠道覆盖倍率、订阅档位、缓存写入费用、流式失败重试均可能改变请求结果或余额。管理员应核对渠道及分组价格配置；不把“无 HCAI 文本冲突”解释为零功能影响。

## HCAI 定制影响

保留 GPT-6.2 `developer` 稳定指令修复、模型广场渠道展示价优先、OpenCode 导出、中英管理文案。插件管理、支付、CC Switch、多节点锁与首页的核心文件未被上游直接改动。定价与网关用量是交叉路径，已做源码和自动测试审查；真实上游 OAuth `cached_tokens` 与生产账单、支付、多节点及迁移尚未现场验证。

## 放行条件与回退

本地完整测试、最终远程 Backend checks/Frontend checks、CODEOWNER 审核、main 上的正式 Release 四附件与 SHA-256 核验完成后，才可给出版本可部署结论。生产部署需另行确定时间、备份和区域顺序；本审查不授权上线。上线后重点监控 GPT-6.2/Ultra Fast 成本、缓存读写 token 桶、429/流式重试和迁移错误。若成本异常或迁移失败，停止后续节点；程序回退使用上一版 HCAI 包，新增列保留并评估旧程序兼容，不删除迁移记录。

合并证据见[上游合并记录](上游合并记录-0.2.23-hcai(fix1).md)，测试与发行状态见[版本发布记录](版本发布记录-0.2.23-hcai(fix1).md)。
