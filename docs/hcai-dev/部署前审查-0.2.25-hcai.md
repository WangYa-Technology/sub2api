## 二、对功能有什么影响

- API key billing 的缺省合同保持；显式 include=group（支持逗号/重复参数）才查询分组本地化文字。上游声明是远端信息，不能证明真实扣费和余额。
- 分组同步默认关闭；开启会使成功探测覆盖本地名称/备注，空字段保留原值，失败不更新；倍率同步仍单独控制。手动按钮可填表单或在列表显式保存，预览不写探测快照。保存账号的 key 不得搭配草稿 URL/代理，URL/代理变化需重输密钥。
- 普通编辑不再无条件写回名称/备注；新 settings 接口用 SetName/SetNotes 表达明确修改，防止覆盖并发同步文字。数据库行内同时写快照、倍率/文字、历史与 outbox；当前关闭开关可阻止在途分组同步。
- 模板可显式将内部 user_id/api_key_id/group_id/request_id 发给配置的 API-key 上游；OAuth/无上下文不发送变量头，WS 按身份分桶且握手不发 request_id。启用前需确认业务披露范围；后台额度/共享模型请求保持无入站用户身份。
- 客户端现在可能收到更精确且已净化的错误 type/code/param/message，并按管理员规则返回；compact 流的容量降载码改变客户端重试行为。这是可见协议变化，需要失败路径回归。

完整文件名核验：317 个 HCAI SQL 与第一父逐字节一致，并完整包含上游的 305 个 SQL，另有 12 个 HCAI SQL；无本轮迁移，也无已发布迁移改写。不能从这一事实推断生产已应用任何历史迁移；升级前仍要从备份恢复的隔离环境核实实际迁移清单、完整文件名校验、启动锁与旧程序兼容。

分组开关为 accounts.extra.upstream_billing_group_sync_enabled，新增模板复用 credentials.header_overrides，无必填环境变量。Go 1.27.4、Node 22.23.4、pnpm11.10.0 不变；本地 Node24.22.3 不作为规定工具链验证。前端锁文件、workspace overrides、MinIO/three 保留，websocket 新依赖的下载/校验/编译待提交步骤。

混版本时旧节点没有分组同步托管键，普通 Extra 全量编辑可能丢失新开关，旧后台探测不更新名称/备注。旧程序不能解析模板变量，可能发送字面模板或产生不同头值；因此全部相关网关/作业节点升级并验收前，不启用新模板或自动分组同步，限制混版本期间账户配置编辑。错误响应语义和 WS 连接池身份分桶也不能保证跨版本一致；摘流排空旧流/WS 后逐节点升级。保留既有 Token stats v2 防不同口径缓存混用，不推导所有缓存即时强一致。

已有 TLS 模板服务刷新后复用旧 Transport 仍可能持旧指纹的限制未在本轮修复，详见历史自定义清单与功能影响审查；不是本次新增实现。

## 回退约束

本轮无新 DDL，旧程序原则上可继续使用现有表；仍需在实际备份副本验收。回退前关闭分组自动同步、移除新模板变量并恢复此前 header_overrides 配置，再排空新程序连接并切换已核验旧 HCAI 产物。仅换旧二进制不会恢复已同步覆盖的名称/备注，须用升级前配置/审计记录恢复；不要以回退名义改倍率或账本。

新错误码/规则行为在旧程序会回退，须复核客户端失败重试。保留数据库历史/缓存/租约表，不删表、不清 Redis、不移动标签；共享 DB 恢复影响所有节点和新订单/用量，必须另行授权。禁止使用默认上游 install/compose 下载替代 HCAI 产物。
