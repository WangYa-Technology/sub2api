## 一、上游 changes

上游 0.2.26 的固定范围包含：

- Anthropic URL image source 与 image-safety 风险控制、异步图片/用量和错误处理回归；
- Responses/Chat bridge 的 null tool index、object arguments、terminal event、tool failover、thinking usage 和 Gemini thought signature 兼容；
- Antigravity quota 精度、QUOTA_EXHAUSTED 切换、并行工具图片和摘要行为；
- OpenAI WS v2 透传 TTFT 时序、compact SSE keepalive/failure、模型/会话提示和 Kimi K3.1 兼容；
- Grok 免费额度缓存测试隔离，账户代理数量刷新与失败回退，usage/help tooltip 的视口定位；
- OAuth 首登表单、刷新租约相关回归，渠道响应模型暴露和账户用量刷新；
- 依赖锁文件中上游 websocket 修复版本及相应 Go/前端测试更新。

固定上游顶层提交还包含撤销其 updater checksum 变更的提交。HCAI 自定义的更新/发行边界按第一父保留，不能把上游提交历史解释为 HCAI Release 证据。

## 二、功能影响

用户可见的影响主要是新的图片安全拒绝记录、桥接协议更完整的工具/错误/usage 事件、WS 透传首 token 计时更贴近 SSE 规则、Grok 免费额度刷新更稳定、代理账户计数及时刷新，以及 tooltip 在窄屏/滚动中的位置变化。API 客户端可能看到更细的事件字段和终止/重试语义；客户端失败重试和监控规则需要按新测试重新核对。

展示价和实际扣费仍是两条链路：模型广场渠道展示优先与官方独立参考价保留，账户/分组真实扣费解析未因上游 tooltip 或 pricing 变更而切换。支付、兑换销售价和返利来源账本没有获得真实支付验证。
